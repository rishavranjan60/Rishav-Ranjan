# Rishav Ranjan — HTML Practice

A small HTML practice repository containing [index.html](index.html) and [hello.html](hello.html).

## View locally

Clone this repository and open `index.html` in a web browser. No package installation or build step is required.

For an optional local server, run the following from the repository root with Python 3 installed:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Open http://localhost:8000 and stop the server with Ctrl+C.
